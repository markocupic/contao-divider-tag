# Contao Divider Tag

Inhaltselement und Formularfeld für Contao, das eine einfache Trennlinie (`<hr>`) ausgibt.
Einfach den Elementtyp **Trennlinie** (`divider`) wählen und speichern.

Dieses Paket ist ein Fork von [stefansl/contao-divider-bundle](https://github.com/stefansl/contao-divider-bundle)
von Stefan Schulz-Lauterbach, angepasst an Contao 5.3, 5.7 und Contao 6.

## Anforderungen

- PHP ^8.1
- Contao ^5.3 oder ^6.0

## Installation

```bash
composer require markocupic/contao-divider-tag
```
